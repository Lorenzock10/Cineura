Integrantes: Matías Fraiman, Jonathan Glitman y Lorenzo Creo Kocher

Descripción del proyecto:Cineura es una plataforma cinematográfica que combina inteligencia artificial y comunidad para transformar la manera en que las personas descubren, eligen y disfrutan películas.
A través de Nova, su asistente de inteligencia artificial, ofrece recomendaciones personalizadas según los gustos, el estado de ánimo, las preferencias y el tiempo disponible de cada usuario. Además, permite explorar un catálogo de películas, crear listas de favoritos, guardar películas pendientes, compartir reseñas, realizar valoraciones y descubrir el ADN cinematográfico personal.

Funcionalidades:
- Recomendaciones con IA (Nova): permite encontrar películas según los gustos, el estado de ánimo, la temática y el tiempo disponible del usuario.
- Explorador de películas: ofrece un catálogo con filtros por género, año, duración y título.
- ADN cinematográfico: genera un perfil personalizado que identifica los gustos y preferencias cinematográficas de cada usuario.
- Favoritos: permite guardar las películas preferidas en el perfil personal.
- Watchlist: permite guardar películas pendientes para ver en otro momento.
- Reseñas y valoraciones: permite compartir opiniones y puntuar películas mediante un sistema de 1 a 5 estrellas.
- Tendencias: muestra películas destacadas para descubrir nuevos contenidos.
- Perfil personalizado: presenta estadísticas, películas favoritas, actores y directores preferidos.
- Cuestionario inicial: identifica las preferencias del usuario para personalizar su experiencia desde el registro.
- Detalles de películas: proporciona información sobre cada película, incluyendo sinopsis, reparto, director, género, duración y valoraciones de la comunidad.
